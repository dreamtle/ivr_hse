**[ НАЗВАНИЕ ПРОЕКТА ]**

“Веб-приложение для сценарного анализа цепочки поставок и сравнения конфигураций сбытовой сети”

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

Запасы в ОП формируются по договорам и субъективным оценкам менеджеров, что ведёт к завышению запасов и «замораживанию» капитала. Нет инструмента, позволяющего на основе статистики продаж сравнить конфигурации сети и алгоритмы пополнения с учётом хранения, логистики и упущенных продаж.

**[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**

Заказчик: производственная организация с центральным складом и сетью обособленных подразделений (ОП).
Аудитория: руководители сбыта и логистики, аналитики, менеджеры по планированию запасов.

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]** 


Облачная версия: браузеры Chrome, Firefox


**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

Программный продукт будет предоставлять следующие возможности:
* Загрузка исходных данных из файлов .xlsx с установленным форматом
* Настройка конфигурации сбытовой сети: центральный склад, обособленные подразделения (ОП), параметры спроса и запасов
* Моделирование спроса на основе статистики продаж за предшествующие периоды
* Выбор алгоритма пополнения запасов на ОП: периодический, по точке запаса, опционально — по динамическому буферу
* Настройка уровней сервиса по категориям клиентов
* Учёт стоимости доставки в зависимости от вида транспорта (авто/ЖД) и принадлежности организации (собственный/наёмный)
* Многопоточный расчёт нескольких сценариев
* Оценка конфигурации по целевой функции: стоимость хранения запасов на ОП и центральном складе + затраты на логистику + упущенные продажи
* Сравнение конфигураций по суммарной стоимости
* Сохранение результатов расчёта в файлах .xlsx
* Опционально — хранение пользовательских конфигураций цепочки поставок

**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

Анализ продуктов, приближенных к заданному функционалу, показал, что:

* ERP-системы (1С, SAP): поддерживают учёт запасов, но не предназначены для быстрого сравнения произвольных конфигураций сети и требуют внедрения и настройки

* Электронные таблицы (Excel): гибкие, но расчёт сценарной модели вручную трудоёмок, не поддерживает многопоточность и воспроизводимость
